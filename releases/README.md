## Local Versioned Archive (`apks/`)

Every compiled version is preserved locally in the `apks/` directory (e.g. `apks/DDMC_v2.0.7.apk`, `apks/DDMC_v2.0.8.apk`, `apks/DDMC_v2.0.9.apk`). The `apks/` directory is kept offline and excluded from Git.

---

## Installation via ADB

To install DDMC on a connected Android device:

```bash
adb install -r DDMC.apk
```
